# 2026-08-13 AI Prompt 与视觉一致性改动日志

## 目标

本轮统一血压解读、行动建议的后端数据与 GPT 输出结构，并修正三餐规则、场景选择、血压卡片以及深色模式下运动卡片的视觉一致性。TestFlight 构建号由 9 升级为 10。

## 血压解读

- 模块标题统一为“血压解读”。
- 输出结构固定为“血压情况 / 原因 / 下一步”，每部分最多三句。
- 后端先按用户时区计算每日血压平均值，再比较最近 3 天与前 3 天、最近 7 天与前 7 天，避免让模型自行计算趋势。
- 当前家庭血压以 135/85 mmHg 作为偏高参考线，同时提供诊室范围比较；措辞保持非诊断、可行动、支持性表达。
- 原因分析向模型提供近期餐食、运动、Apple Health 最近同步值和用户基础资料；最近 3 天优先，最近 7 天作背景。
- 下一步建议依据当前读数、安全症状和趋势结果分为继续观察、规范复测或建议咨询医生。
- API 同时保留旧版响应字段，避免已安装的旧 TestFlight 客户端在后端更新期间解码失败。

## 行动建议

- 行动调整底部模块由“趋势调整”统一为“行动建议”。
- 饮食输出固定为“饮食结构 / 烹饪方式”；运动输出固定为“运动时段 / 运动类型”。
- 后端读取真实餐食分析和运动记录，计算完成率、预约与实际完成时段、实际时长和运动类型分布。
- 只要存在至少一条真实记录就生成具体、克制的结论；只有记录数为零时才说明暂无记录，不使用“记录还比较少”等模糊措辞。
- GPT 请求采用结构化 JSON Schema，且设置 `store: false`。

## iOS 界面

- 行动生成与行动调整中的“今日最新血压”卡片统一为蓝底白字，保留橙色“建议复测”提示。
- 三餐黄色规则卡标题统一为“建议时间”，删除标题后的数字时段，只保留具体规则说明；无障碍标签同步更新。
- 场景选择恢复简洁的 SF Symbols 图标，删除“例如”前缀。
- 全局固定浅色模式，并在 Info.plist 声明 Light，避免部分设备系统深色模式导致运动卡片背景变灰、文字变白。
- 运动建议区明确使用深色正文，保证不同设备和显示模式下均可读。
