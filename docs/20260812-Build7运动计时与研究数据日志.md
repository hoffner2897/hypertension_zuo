# BPHealth Build 7 变更日志（2026-08-12）

## 用户界面

- 男性档案改用男性头像，16 个低门槛运动逐项替换为对应男性动作图片；其他、不想说明和未选择性别继续使用女性资源。
- 今日行动的树固定为五阶段成长；当日完成率只会上升，不会因错过行动或删除行动倒退。
- 时间轴继续按同侧卡片实际高度避免重叠，同时缩短顶部、底部、同侧和时间间隔留白。
- 血压相关的最新读数统一为“今日最新血压”。
- 行动生成与行动调整使用一致的今日最新血压卡片。
- 最近 7 天趋势图例改为两行：第一行收缩压、第二行舒张压。

## 运动计时

- 所有低门槛运动和自定义运动的详情页支持开始、暂停、继续和提前结束。
- 倒计时基于绝对时间计算，App 进入后台后仍可正确恢复。
- 首次计时申请本地通知权限，计划时长到达时发送提醒。
- 时间到不会自动完成；用户需确认完成、继续运动或提前结束。
- 记录实际开始、结束、实际时长和完成方式。

## 删除和研究数据

- 仅今日运动支持“删除今日行动”，并显示二次确认。
- 删除后从今日时间轴和完成率分母中移除。
- 后端使用软删除：原运动计划、计时、完成和删除时间仍保留，便于匿名研究分析。

## 后端迁移

- 新增迁移 `20260812120000_exercise_timer_and_soft_delete`。
- `exercise_actions` 新增实际计时、完成方式和软删除字段。
- 新增 `DELETE /exercise-actions/:id`，返回 204，列表默认排除已删除行动。

## 验证

- Node TypeScript 检查通过。
- Node 测试 32 项：30 通过，2 项真实环境 E2E 按设计跳过。
- iOS App 在 iPhone 14 Pro 模拟器编译通过；单元测试通过。
