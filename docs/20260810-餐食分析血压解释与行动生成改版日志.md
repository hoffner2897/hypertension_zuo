# BPHealth 餐食分析、血压解释与行动生成改版日志

时间：2026-08-10（Europe/London）

状态：本地实现与自动验证已完成；尚未提交、推送、部署 Render 或上传 TestFlight。

## 本轮确认范围

1. 餐食 AI 分析改为“识别 / 饮食结构 / 烹饪方式”三段；类似建议改为“饮食结构 / 烹饪方式”两段。
2. 恢复血压读数解释卡片，位置在读数卡片下、最近 7 天趋势上。
3. 最近 7 天趋势补充按日平均值说明。
4. 今日行动血压卡片内部移除时间；中轴保留时间。早晨计划改为 07:00，晚间保持 21:30。
5. AI 强度建议的 bullet 改造由需求方明确取消，本轮不修改。
6. 场景、状态、4 项实时运动推荐、运动时长和预约开始时间合并为“生成低门槛运动”。
7. “偏好运动设置”更名为“记录自定义运动”。

## 餐食 AI 与持久化

- OpenAI Responses API 改为严格 JSON Schema，返回五段结构化正文与卡片摘要。
- Prompt 要求每段只写一句话，并从 DASH、少盐、少加工食品、蔬果与优质蛋白合理搭配等支持血压管理的角度分析。
- 对照片无法证明的盐、油、分量和烹饪方式使用谨慎措辞；不输出精确营养数字，不诊断，不提供药物建议。
- `meal_records` 新增五个可空结构化文字字段。历史记录继续使用旧字段展示；新记录同时写入结构化字段和合成后的旧字段，兼容旧版客户端。
- 餐食图片仍不上传或保存到服务器；同机再次打开时继续使用本地轻量图片缓存。

## 血压读取与趋势

- 已存在的 `/readings/interpretation` 后端规则、GPT 润色和 iOS 展开式解释卡重新接入页面。
- 解释卡不改变规则拥有的血压类别与安全等级；GPT 仅优化支持性表达。
- 最近 7 天趋势仍按自然日聚合，同一天多次读数先分别计算收缩压与舒张压平均值，再呈现趋势。

## 行动生成

- 单页流程为：选择场景 → 选择精力与情景状态 → 从即时更新的 4 项推荐中选择 → 选择时长与预约时间 → 生成今日运动。
- 运动候选仍来自既有的 4 场景 × 每场景 6 项目录及确定性评分规则；每次状态变化只展示排名前 4 项。
- 明显不适或血压安全状态阻止运动生成时，页面显示先休息并复测的支持性提示。
- 自定义运动保持独立弹窗，仅更改用户可见名称与说明。
