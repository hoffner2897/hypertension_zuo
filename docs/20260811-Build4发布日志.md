# BPHealth 1.0（Build 4）发布日志

时间：2026-08-11（Europe/London）

基线：GitHub 提交 `4df3a92`（修复三餐弹窗关闭并更新低台阶文案），发布提交以最终 Git SHA 为准。

## 发布内容

- 包含 BPHealth Build 3 的完整 iOS、Node API 与 PostgreSQL 改版。
- 修复早餐、午餐、晚餐记录弹窗首次打开时右上角关闭按钮无响应的问题。
- 仅删除两个场景下“低台阶踏步”中“首次练习建议查看动作视频”的提示，其他运动提示保持不变。
- 保持结构化餐食分析的五项后端字段与两张前端结果卡片。
- iOS 版本保持 `1.0`，构建号升级为 `4`。

## 发布目标

- GitHub：`hoffner2897/hypertension_zuo` 的 `pre-approve` 分支。
- Render：`bphealth-api-staging`，根目录 `server`，健康检查 `/health`。
