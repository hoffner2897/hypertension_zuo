# BPHealth 1.0（Build 8）发布日志

日期：2026-08-12

## 本次改动

- 注销账户时将原邮箱保留到研究字段，同时匿名化登录邮箱，允许同一邮箱再次注册。
- 今日行动三餐卡片保留具体时间点，并新增始终可见的黄色建议时段与行为规则。
- 行动生成和行动调整统一使用黄色“今日最新血压”卡片并压缩高度。
- 血压读数入口合并为“上传读数”，进入后提供拍摄、相册和手动输入；移除多余图标及确认/编辑页头像。
- 行动调整只展示运动，并将 GPT 趋势建议移动至血压卡片下方。
- 更新四类场景的图片及说明。
- 需要休息、复测或用户明确不适时，仅清除当天未完成运动；三餐、血压和已完成运动研究记录保留。
