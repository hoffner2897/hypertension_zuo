# Build 13 强制更新发布说明

## 目标

- iOS 请求携带 Build 号。
- 后端可配置最低支持 Build，并对旧版本返回 `UPDATE_REQUIRED`。
- App 收到该响应后显示不可关闭的 TestFlight 更新页。
- Render 健康检查不受版本门槛影响。

## 安全发布顺序

1. 部署后端与 Build 13 客户端代码，保持 `MINIMUM_SUPPORTED_IOS_BUILD=0`。
2. 上传 Build 13，并确认其在 TestFlight 中进入 `Testing`。
3. 设置 `MINIMUM_SUPPORTED_IOS_BUILD=13`。
4. 验证无 Build 号及 Build 12 请求返回 `426`，Build 13 正常通过版本校验。

## 回滚

如 TestFlight 更新入口或 Build 13 出现问题，将 `MINIMUM_SUPPORTED_IOS_BUILD` 恢复为 `0` 即可立即解除后端版本拦截。
