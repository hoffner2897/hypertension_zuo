# BPHealth 1.0（Build 6）发布日志

日期：2026-08-11

## 本次改动

### 行动调整图片映射

- 修复从低门槛运动或自定义运动切换为新的低门槛运动后，仍显示自定义运动通用图片的问题。
- 调整后的低门槛运动会重新绑定正式运动目录 ID、场景、精力信息、固定“怎么做”和“强度建议”文案。
- 今日行动和行动调整统一根据目录 ID 解析男女对应的运动图片。
- 用户自由填写的自定义运动继续使用统一的自定义运动图片。

### 今日血压手动录入

- 在“血压读数”首页增加“手动输入读数”。
- 在“拍照上传”页面增加“手动输入读数”。
- 手动录入复用现有确认页面、校验、本地保存、离线队列和后端同步流程。
- 本版本手动录入仅记录今天；用户只能调整当天的测量时间，默认使用当前时间；从今日行动进入且计划时间已经到达时，可沿用该计划时间。

## 验证结果

- iPhone 14 Pro 模拟器完整单元测试通过。
- iPhone 14 Pro 血压手动录入与拍照入口 UI 回归测试通过。
- 调整后的低门槛运动目录映射及卡片图片回归测试通过。
- 本次无需修改 Node API 或 PostgreSQL 数据结构。
